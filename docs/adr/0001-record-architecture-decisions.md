# 1. Record architecture decisions

Status: Accepted (2026-10-20)

## Context

Decisions about Mailbridge were scattered across commit messages and the README, so the reason behind a choice was hard to find later.

## Decision

Each real decision gets a short record here: context, decision, consequences. A record is never rewritten; a later decision supersedes it and says so.

## Consequences

Reviewers can check a change against the decisions it touches. New decisions cost a few minutes of writing.
